## 3. Pasos Ejecutados

1. **Conexión de TV Nueva en Espera:**  
   Se abrió conexión WebSocket hacia `/control` con parámetros `?session_code=7788&waiting_pairing=true`.
   * *Resultado:* Conectado con éxito. Socket ID: `GB1Cr6vQ5NYnHqV1AAAE`.
2. **Detección en la Consola de Administración:**  
   Se consultó el endpoint de polling `GET /api/admin/waiting-screens`.
   * *Resultado:* HTTP 200. El PIN `#7788` fue listado inmediatamente con su timestamp y socket ID.
3. **Disparo de Asignación Remota:**  
   Se ejecutó `POST /api/admin/bind-screen` con body `{ sessionCode: "7788", tv_uuid: "7c818233-2fb5-4436-98d2-127a6426a594" }`.
   * *Resultado:* HTTP 200, mensaje: `"Pantalla vinculada exitosamente con el perfil PT4123 (Piso 4 - Pruebas)."`.
4. **Recepción del Evento en la TV:**  
   El socket cliente de la TV escuchó el evento `command:assign_profile`.
   * *Medición de Latencia:* **11 milisegundos**.
   * *Payload Recibido:* Objeto completo del perfil (`name: PT4123`, `location: Piso 4 - Pruebas`, `tv_uuid: 7c818233-2fb5-4436-98d2-127a6426a594`).
5. **Comprobación de Estado en Backend:**  
   Se consultó de nuevo `GET /api/admin/waiting-screens`.
   * *Resultado:* La sesión `#7788` fue removida exitosamente de la lista de espera.
6. **Prueba de Reconexión Directa:**  
   Se desconectó el socket en espera y se reconectó uno nuevo pasando únicamente `?tv_uuid=7c818233-2fb5-4436-98d2-127a6426a594`.
   * *Resultado:* Conectado como dispositivo registrado en la sala `tv:7c818233-...` sin solicitar PIN.
   * Se emitió `tv:heartbeat` satisfactoriamente.
7. **Restauración de Estado:**  
   Se ejecutó `UPDATE nexus_tv.tv_screens SET last_login = NULL WHERE id = 7;` restaurando `PT4123` a su estado exacto inicial.
