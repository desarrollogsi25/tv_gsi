## 3. Evidencias Técnicas

### 3.1. Discrepancia Física en Almacenamiento
* **Registros en Base de Datos:** **28 archivos** locales registrados en `nexus_tv.content` con prefijo `/media/176...`.
* **Archivos Físicos en `/app/media`:** **4 archivos** existentes (`1790102952871-...`, etc.).
* **Archivos Coincidentes:** **0 archivos**.
* **Resultado HTTP:** El **100% (28 de 28)** de los contenidos locales de la base de datos devuelven **HTTP 404 Not Found**.

### 3.2. Asimetría en Manejadores de Error en `TVPlayer.jsx`
1. **Elemento `<video>` (Línea 640 y 406-409):**
   ```javascript
   const handleVideoError = (err) => {
       console.warn('Video playback error, auto-advancing:', err);
       setTimeout(handleNext, 2000);
   };
   ```
   * *Comportamiento:* Aplica un retardo de **2.000 ms** antes de avanzar, mitigando bucles cerrados.
2. **Elemento `<img>` (Línea 650):**
   ```javascript
   <img
       className="tv-media-element tv-image-player"
       src={currentItem.source_url.startsWith('http') ? currentItem.source_url : `${API_BASE}${currentItem.source_url}`}
       alt={currentItem.title}
       onError={handleNext}
   />
   ```
   * *Comportamiento:* Invoca `handleNext` **de forma inmediata y síncrona** (`0 ms de backoff`).

### 3.3. Determinación de Impacto ante Múltiples Archivos Inexistentes
* Dado que los 28 contenidos faltantes son imágenes (`.png` y `.jpg`), cuando una pantalla se encuentra con elementos consecutivos inexistentes:
  1. El navegador emite petición GET y recibe `HTTP 404`.
  2. El evento `onError` del elemento `<img>` se dispara inmediatamente.
  3. Se ejecuta `handleNext()` modificando el estado `currentIndex`.
  4. React re-renderiza el siguiente ítem de la lista.
  5. Si el siguiente ítem también es una imagen inexistente, se repite el paso 1 instantáneamente.
* **Consecuencias Críticas Observadas y Clasificadas:**
  * **Bucle Rápido Descontrolado (Rapid-Advance Loop):** Cientos de llamadas por segundo al backend solicitando imágenes 404.
  * **Saturación del Event Loop y 100% de CPU:** Congelamiento del hilo de UI del navegador.
  * **Pantallazo Negro Parpadeante:** La pantalla no logra renderizar nada estable y parpadea en negro.
  * **Riesgo de Crash de React:** Posible desborde de pila o error `Maximum update depth exceeded` si la cascada se acelera.

---

## 4. Conclusión y Clasificación

* **Clasificación:** ❌ **FALLIDO (Bug Confirmado)**
* **Incidente Asociado:** **BUG-002** (`docs/11-incidents/bugs/BUG-002-missing-media-404.md`) / **RSK-014**.
* **Severidad:** **Alta**
* **Prioridad:** **P0**
* **Justificación:** La totalidad de los medios locales en BD no existen en el volumen `/app/media`, y la ausencia de retardo (`debounce`/`backoff`) en el `onError` de imágenes produce un bucle destructivo de avance rápido que degrada el rendimiento del navegador y del backend.
