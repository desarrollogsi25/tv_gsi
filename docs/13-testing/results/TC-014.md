## 3. Evidencias Técnicas

### 3.1. Inspección de Código Fuente en `nx_tv.js`
```javascript
// nx_tv.js (L50-52)
app.use(cors({ origin: '*' }));
app.use(express.json({ limit: '300mb' }));
app.use(express.urlencoded({ extended: true, limit: '300mb' }));

// Montaje de rutas directas sin middlewares de autenticación (L92-94)
app.use('/api/tv', tvRoutes);
app.use('/api/admin', adminRoutes);
app.use('/api/tv-content', mediaRoutes);
```
* **Ausencia de Middlewares de Seguridad:** No existe ningún middleware de verificación de credenciales (JWT, Basic Auth, Session, API Key o verificación de roles RBAC).
* **CORS Permisivo Irrestricto:** La directiva `origin: '*'` permite que cualquier origen externo realice peticiones HTTP cruzadas con credenciales anónimas hacia el backend.

### 3.3. Impacto de Seguridad (ISO 27001 Control A.9)
1. **Acceso Anónimo Total a Operaciones Administrativas Críticas:**  
   Cualquier cliente dentro de la red corporativa puede:
   * Controlar remotamente pantallas (`POST /api/admin/screens/:uuid/control`).
   * Emitir transmisiones prioritarias y suplantar contenido en vivo (`POST /api/admin/temporary-content`).
   * Eliminar activos multimedia y subidas (`POST /api/tv-content/delete`).
   * Desvincular o reasignar dispositivos Kiosk (`POST /api/admin/bind-screen`).
2. **Exposición Cross-Origin (CSRF / Drive-By Attacks):**  
   Al permitir `Access-Control-Allow-Origin: *`, un usuario navegando en internet en una estación de la misma LAN corporativa puede ser víctima de un script malicioso en una pestaña web externa que dispare comandos administrativos hacia la IP interna de Nexus TV.
