## 4. Análisis de Comportamiento y Firma del Payload

1. **Firma del Evento WebSocket:**
   * El backend emite `controlNamespace.to('tv:' + uuid).emit('command:execute', { command, payload: payload || {} })`.
   * La firma recibida coincide exactamente con la esperada por el cliente: `{ command: string, payload: object }`.
2. **Desacoplamiento y Velocidad:**
   * La latencia media de propagación tras el primer comando fue de **2 a 3 milisegundos**.
   * La respuesta HTTP administrativa confirma el despacho inmediato (`{"success":true,"message":"Comando '...' enviado correctamente."}`) sin bloquear el hilo del servidor.
3. **Manejo de Errores en Player:**
   * En `TVPlayer.jsx` (línea 263-264), `videoRef.current.play().catch(() => {})` previene errores no controlados si el navegador bloquea la reproducción de video por políticas de autoplay.
