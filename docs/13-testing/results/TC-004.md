## 3. Evidencias Técnicas

### 3.1. Ausencia Total de Media Queries
* **Reglas `@media` encontradas:** **0 coincidencias** en todo `Admin.css`.
* Toda la hoja de estilos utiliza valores fijos en píxeles y dimensiones estáticas sin ningún breakpoint de adaptación.

### 3.2. Estructura Rígida del Layout
```css
.admin-layout {
    display: flex;
    min-height: 100vh;
    width: 100vw; /* Ancho forzado */
    background-color: var(--bg-canvas);
}

.admin-sidebar {
    width: 280px; /* Ancho fijo inmutable */
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    border-right: 1px solid var(--border-sidebar);
}

.admin-container {
    flex: 1;
    display: flex;
    flex-direction: column;
    height: 100vh;
    overflow: hidden; /* Oculta desbordamiento */
}

.admin-main {
    flex: 1;
    padding: 40px 44px; /* 88px de padding horizontal */
    overflow-y: auto; /* Solo scroll vertical */
}
```

### 3.3. Comportamiento en Viewports de Tablet y Laptop ($\le$ 1024px y $\le$ 768px)
* **En Viewport de 768px (Tablet Portrait / iPad):**
  * Sidebar consume **280px** (36.5% del viewport). No existe menú hamburguesa, cajón colapsable ni toggle para ocultarlo.
  * Espacio restante para contenido: `768px - 280px = 488px`.
  * Relleno lateral de `.admin-main`: `44px + 44px = 88px`.
  * **Ancho neto disponible para el contenido:** **400px**.
  * **Colapso de Tablas (`.nexus-table`):** Las tablas de administración (Catálogo multimedia con 6 columnas, listas de reproducción) tienen un ancho intrínseco mínimo de ~650px a 800px.
  * Dado que `.admin-container` tiene `overflow: hidden` y `.admin-main` tiene `overflow-y: auto` (sin `overflow-x: auto`), **las columnas derechas de las tablas y botones de acción quedan recortados visualmente**, inaccesibles para el usuario sin scroll horizontal.
* **En Viewport de 1024px (Tablet Landscape / Laptop compacta):**
  * Ancho disponible: `1024px - 280px - 88px = 656px`.
  * La grilla de pantallas `.tv-grid` (`repeat(auto-fill, minmax(340px, 1fr))`) solo permite 1 tarjeta por fila con espacios desbalanceados.
  * La barra superior `.admin-topbar` (padding `44px` a cada lado) comprime el título contra los badges de estado.

## 4. Conclusión y Clasificación

* **Clasificación:** ❌ **LAYOUT ESTÁTICO NO RESPONSIVO (Bug Confirmado)**
* **Incidente Asociado:** **BUG-003** (`docs/11-incidents/bugs/BUG-003-static-admin-layout.md`).
* **Severidad:** **Media**
* **Prioridad:** **P2**
* **Justificación:** La consola carece totalmente de diseño adaptable (`@media`). En dispositivos con ancho $\le 1024px$, la barra lateral fija de 280px y el padding restrictivo generan desbordamiento horizontal y truncamiento de tablas de datos y botones de acción.
