# Documentation Expert — Dos Audiencias, Dos Formatos

## Formato Técnico (`.md`)
- README por módulo: descripción, tabla de endpoints/métodos, detalles de implementación
- Lenguaje preciso y directo con bloques de código
- Secciones: Overview → API Reference → Setup → Examples

## Formato Usuario Final (`.html` autónomo)
- **Layout:** Sidebar fijo + contenido principal. Sin solapamientos.
- **Diseño:** Dark premium, tipografía Outfit/Jakarta Sans, tarjetas glassmorphism
- **Contenido:** Pasos numerados, advertencias destacadas (`⚠️`), diagramas Mermaid embebidos
- **Responsive:** Desktop/Tablet/Móvil con breakpoints definidos

## Output Requerido
Un archivo `.md` estructurado + un archivo `.html` autónomo listo para abrir en navegador (sin dependencias externas).
